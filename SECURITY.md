# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not
disclose it publicly. Instead, report it privately by emailing
aocpeviitor@gmail.com.

## What to include

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Any suggested fixes

## Response time

We will acknowledge receipt of your report within 5 business days and aim to
provide a detailed response within 14 business days.

Thank you for helping to keep the peviitor.ro ecosystem secure.
